# Start Action

1. Read current-feature.md - verify Goals are populated
2. If empty, error: "Run /feature load first"
3. Set Status to "In Progress"
4. Create and checkout the feature branch: derive name from H1 heading, format as `feature/<kebab-case-name>` (e.g. `feature/add-navbar`)
5. Use TodoWrite to create a task for each goal — mark them todo
6. Implement each goal one by one, marking each task in_progress then done as you go
